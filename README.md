during my master's studies at Arizona State University:

## How the three courses connect

Together, the three courses approach machine learning from complementary
perspectives:

1. **CSE 575** introduces the major models, algorithms, and evaluation methods
   used in statistical machine learning.
2. **Statistical Learning Theory** asks why a model learned from a finite
   training sample should perform well on unseen data, and how its objective
   can be optimized.
3. **Modern Temporal Learning** studies how these ideas change when observations
   are ordered and dependencies develop through time.

A simplified progression is:

```text
What models and algorithms can we use?
                    ↓
Why should the learned model generalize?
                    ↓
How do we model data whose order and timing matter?
