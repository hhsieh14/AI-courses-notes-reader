# CSE 575: Statistical Machine Learning

My notes from CSE 575 at Arizona State University, rewritten as a readable reference. They cover the core toolkit of classical machine learning: how models are fit, how they fail, and how to evaluate them. The math is derived step by step, and I've added short **"Beyond the lecture"** notes where practice or theory goes further than the lecture did.

## How each chapter is built

- Derivations are written out in full, not just stated.
- **Intuition** boxes give the one-sentence version.
- **Beyond the lecture** boxes add what I've learned since: practical pitfalls, stronger results, and links to my [learning-theory](../statistical-learning-theory/README.md) and [time-series](../modern-temporal-learning/README.md) notes.
- Each chapter ends with common mistakes, a summary, and self-check questions with answers.
- Code snippets are small and runnable; every one was executed to produce the numbers shown.

Figures in `docs/assets/diagrams/` marked `.svg` are generated by [`src/make_diagrams.py`](docs/assets/diagrams/src/make_diagrams.py), so their geometry is computed rather than sketched.
